📖 Cara Setup Google Spreadsheet Sekolah (Hanya 3 Menit)
  1. Buka Google Spreadsheet baru: sheets.new ↗
  2. Buka menu Extensions (Ekstensi) > Apps Script.
  3. Salin skrip dari berkas google_apps_script_cloud_sync.js dan tempel ke editor Apps Script.
  4. Pilih fungsi initialSetupSheets lalu klik Run (Jalankan) untuk otomatis membuat seluruh lembar tabel & rumus.
  5. Klik tombol biru Deploy (Terapkan) > New deployment > Web app:
    • Execute as: Me
    • Who has access: Anyone (Siapa saja)
  6. Salin Web app URL yang muncul dan tempelkan ke kotak input di atas!
